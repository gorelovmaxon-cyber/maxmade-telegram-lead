# MAXMADE — Telegram-лиды и правила первого отклика

Репозиторий содержит две связанные части:

1. **Система мониторинга заказов** — код, который читает выбранные Telegram-источники,
   отбирает подходящие заявки и присылает карточки в рабочий Telegram владельцу.
   Карточка содержит задание, источник и черновик первого отклика.
2. **Правила первого отклика** — документы, по которым пишется текст ответа заказчику,
   и исследовательская база под ними (выжимки видео и транскрипты).

## Состав

| Каталог | Что внутри |
|---|---|
| `telegram-monitor/` | Рабочий код: приём, фильтр, очередь доставки, бот, ИИ-черновики, аудит сайта клиента, тесты, служебные документы, шаблоны systemd. |
| `документы/` | Задание на Telegram-монитор, задание на новый аккаунт, обзор Telegram-канала как источника. |
| `каталоги-Telegram/` | Каталоги 39 и 49 Telegram-источников с разбором и оригиналы подборок. |
| `тексты/` | Правила и тексты первого отклика (15–17), исследование видео и финальная сводка (18–19), слои отбора источников, выжимки и транскрипты. |

Входная точка по коду — `telegram-monitor/README.md` и `telegram-monitor/HANDOFF.md`.

## Чего в репозитории нет

Рабочие данные и секреты сознательно не публикуются:

- `.env`, токены бота, API-ключи, настройки ИИ;
- SQLite-базы монитора, очередь доставок, журналы и снимки состояния;
- профиль Chrome и сессии аккаунта (`state/`);
- виртуальные окружения и кэши.

Документы других каналов привлечения и служебные задания по публикации/переносу
в этот репозиторий не входят.

## Локальная проверка

Нужен Python 3.12 или новее.

```text
cd telegram-monitor
python -m pip install -r requirements-client.txt -r requirements-ai.txt -r requirements-browser.txt
python -m playwright install chromium
python -m unittest discover -s tests -q
```

ИИ-черновики работают только при настроенных `MONITOR_AI_*` в `.env`; без них
карточки приходят без блока «Наш отклик». Подробности — `telegram-monitor/README.md`
и `.env.example`.

## Ограничения

- Чтение групп идёт от обычного аккаунта (Telethon) и через локальный Chrome;
  это противоречит правилам Telegram для пользовательских аккаунтов и может
  привести к ограничениям аккаунта. Используйте отдельный аккаунт.
- Встроенный браузерный источник зависит от вёрстки web.telegram.org и требует
  ручного восстановления при разрывах.
- Сбор карточек с бирж (FL.ru, Workspace, Kwork, connect.tg) подчиняется правилам
  этих площадок; проверяйте их перед включением.
- Сообщения групп могут содержать персональные данные. Перед промышленной
  эксплуатацией определите основание обработки и срок хранения.
