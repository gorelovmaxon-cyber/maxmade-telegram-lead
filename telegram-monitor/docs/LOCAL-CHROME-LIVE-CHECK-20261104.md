## Что пока не принято

Новая естественная цепочка **сообщение группы→приёмник→фильтр→уведомление Максиму** пока ожидает нового события и подтверждённого результата. Отсутствие сообщений, успешный getMe и работающий baseline не подменяют эту приёмку. Саморекламу/партнёрство/служебное событие не считать прямым заказом; прямой заказ остаётся отдельной открытой приёмкой. Если фильтр отклонит сообщение, не отправлять его как заказ ради теста.

На старте сохранены63 events/63 candidates/10 deliveries, new62/taken1,sent7/pending3. Сверяются не только суммы: исходные owner_status для всех63 кандидатов и state/message_id всех10 доставок сравниваются с согласованной резервной копией. Локальные квитанции `state/local-chrome/checkpoint-*.json` содержат только служебные признаки и новые публичные ID/ссылки/классификацию/результат доставки, без текстов сообщений/токенов.

Windows task по-прежнему Disabled. Автозапуск после входа Windows/реальный reboot **не реализованы и не проверены**. После закрытия приложения Codex устойчивость ещё не доказана; pythonw пережил завершение запускающей PowerShell, но это не доказывает поведение при закрытии всего приложения. Непрерывность/полнота потока/автовосстановление пропусков не обещаны. Постоянный запуск готовить только после работающего прототипа на одном источнике.
