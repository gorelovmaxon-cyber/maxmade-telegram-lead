## Черновик для Максима

Здравствуйте! Хочу получать новые проектные задания из вашего канала в личные уведомления для отбора подходящих работ. Можно добавить моего бота @uffweb_bot с минимальными правами для получения публикаций, без права публикации и управления каналом? Обработка локальная по обычным правилам; сохраняется небольшой фрагмент до 30 дней, ссылка и статус. Просьба также указать ваши условия такого чтения и сохранения. Если предусмотрен официальный API или другой разрешённый способ подписки для интеграции, готов рассмотреть его.

Это запрос технического доступа, не реклама услуг и не сообщение заказчику. Данные токена/API hash/session/личные числовые ID не включать.

## После фактического предоставления доступа

1. Зафиксировать ответ/правила и дату, проверить соответствие допустимому использованию. Отсутствие запрета в случайном посте не считать разрешением.
2. getMe сверяет @uffweb_bot; getChat по username подтверждает title/username/type/channel_id, getChatMember — присутствие и выданные права. Не включать права публикации ради чтения.
3. Не запускать второй getUpdates: им уже пользуется рабочая доставка. Токен остаётся локальным. Закрепить числовой channel_id только после проверки.
4. Дополнить MONITOR_SOURCE_IDS, сохранив текущие источники, резервную копию конфигурации хранить только локально в state. Клиентский reader группы не заменять.
5. Если для загрузки конфигурации нужен рестарт доставки, убедиться, что нет sending. Перезапускать только необходимый компонент; записать окно обслуживания и не обещать отсутствие пропусков.
6. Дождаться нового допустимого channel_post. Проверить задачу и роль автора, оригинал, дату/получение/отправку, требования/маршрут, черновик или конкретное недостающее, owner-only доставку, replay на изолированной копии с поддельным отправителем. Исторический пример /4933 не превращать в новое потоковое событие.

До шага 1 конфигурация пилота не меняется. Нет доступа — источник остаётся подготовленным, но неподключённым. Клиентский доступ канала требует отдельного адаптера и выполнения условий Telegram; простое удаление проверки megagroup не допускается.
