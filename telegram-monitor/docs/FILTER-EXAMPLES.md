## Пять придут

- Лендинг для курса на Tilda — конкретный проект.
- Переделать сайт компании по рекомендации — конкретный проект.
- Презентация для инвесторов — конкретный проект.
- Интерфейс личного кабинета — конкретный проект.
- Агентство передаёт разработчику сайты — субподряд, отдельный заголовок.

## Пять не придут

- «Делаю сайты. Нужен лендинг? Пишите!» — реклама.
- «Ищу клиентов на разработку сайтов» — продажи для автора.
- «Плачу 35% за приведённого клиента» — обратное направление работы.
- Бухгалтер с сайтом компании в подписи — непрофильная задача.
- «Нашли исполнителя» — закрытие, не новый заказ.

## Пять пограничных

- «Кто занимается сайтами?» — проверка: результат не раскрыт.
- Сайт на Laravel — проверка компетенций, не автоматическое уведомление.
- Сайт и бот одним исполнителем — проверка полного объёма.
- Сайт и бот, можно взять только сайт — уведомление о выделенной части; бот не обещается.
- Штат или проект без объёма — проверка. «Не в штат» само по себе наймом не считается.
