## Проверки

Запущено `.venv\Scripts\python.exe -m unittest discover -s tests -q`: 23 теста, один failure в test_classification_examples. Ожидалось urgent для учебного «Ищу разработчика сайта», получено digest.

Причина видна в коде теста: setUp назначает публикацию на 09:00 UTC текущего дня, а classify сравнивает её с реальным now(). Проверка выполнялась около 05:13 UTC, поэтому публикация получилась более чем на пять минут в будущем. Это зависимость теста от времени запуска, а не доказательство поломки классификации обычного актуального запроса. Зафиксировать часы в тесте либо передавать единый момент времени в классификатор. Прежние 23 OK могли быть правдивы для другого времени суток, но сегодняшний прогон не зелёный.
