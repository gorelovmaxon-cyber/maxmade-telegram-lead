## Правило первого обращения после сверки

Изучить фактический запрос и маршрут → предложить ограниченный способ решения заявленной задачи → назвать подтверждённый релевантный кейс на своём сайте и готовность показать его, **без URL в первом обращении** → один уместный следующий шаг. Не ставить диагноз странице без просмотра, не предлагать полный редизайн из-за небольшой проблемы, не спрашивать уже сказанное. Если автор требует обязательные данные, которых нет, сначала перечислить недостающее без готового сообщения. Отказ означает остановку контакта. Отправляет Максим.

Данные сайта — доказательство опубликованного профиля, а не гарантии исполнения нового проекта. Отсутствие бюджета в коротком запросе не отменяет классификацию «прямой заказ»; отсутствие нашей согласованной цены при обязательном требовании её прислать блокирует готовность отклика. Это разные решения.
