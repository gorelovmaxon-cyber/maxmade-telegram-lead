Эти условия объясняют остановку и отсутствие восстановления утром; индивидуальные exit codes старых PID не сохранились.

Установлена задача Windows **MaxMade-Telegram-Pilot** от текущего пользователя с обычными правами и InteractiveToken, без сохранения пароля. Длительность задачи не ограничена; переход на батарею её не останавливает. `pilot.py stop` отключает задачу и останавливает только процессы проекта; `start` включает обратно. Настройки сна, питания и сети Windows не менялись. Основание параметров: [Microsoft — триггеры](https://learn.microsoft.com/en-us/powershell/module/scheduledtasks/new-scheduledtasktrigger), [настройки задачи](https://learn.microsoft.com/en-us/powershell/module/scheduledtasks/new-scheduledtasksettingsset).
