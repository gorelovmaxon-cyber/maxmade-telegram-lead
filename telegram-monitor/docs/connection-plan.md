Публичная ссылка не даёт нашему боту доступ к сообщениям. Для группы бота можно добавить с нужной видимостью (проверить privacy mode); для канала требуется добавление администратором. Отсутствие такой возможности не исключает **клиентский доступ к группе**, где отдельный аккаунт Максима сам состоит и принимает правила. `reader.py` не вступает в группы, не перебирает участников, не загружает историю и не отправляет сообщения. Для каналов клиентский маршрут сейчас не используется: [API Terms](https://core.telegram.org/api/terms) требуют поддержки официальных sponsored messages при доступе клиентского приложения к контенту каналов. Нельзя считать одно только наличие Telethon разрешением обходить правила источника. Публичный веб-превью, RSS-мосты и скрейпинг не выбраны.
