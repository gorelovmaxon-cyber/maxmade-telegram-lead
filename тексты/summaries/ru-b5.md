### Суть — 5 строк, не больше

1. Скрипт холодного B2B-звонка работает по схеме: кто → тема через выгоду клиента → краткое доказательство (цифра) → один CTA; неопытный оператор (19 лет, 3 месяца) закрывает сделку.
2. Одна показательная запись звонка от компании АСУ XXI Век без данных о конверсии — демонстрация продукта (сценарии звонков), не исследование.
3. Универсально: первое обращение — кто ты + что даёт клиенту + одно целевое действие; работа с привратником: спроси имя, потом питч; не заваливать информацией.
4. Нишевое: B2B холодный звонок, конкретный продукт (семинар для руководителей), выход на замдиректора — модель не переносится в B2C переписку напрямую.
5. Нет разбора неудачных звонков, нет цифр конверсии — одна удачная демонстрация, кроме того транскрипт нечитаем на ~40% слов.

### Про «учли клиента» (§4)

- **Есть ли в видео этот приём:** нет
- **В каком виде:** питч стандартный — без персонализации под конкретную компанию; упоминание «ваших сотрудников» и их нагрузки есть, но текст нечитаем ([неразборчиво]), проверить невозможно

- **Вердикт:** брать с оговоркой
